# Complete API Contract

## Base URL
- **Express Backend:** `https://api.arthora.in/v1` (deployed on Railway)
- **Web App** calls the Express backend via `NEXT_PUBLIC_API_URL` env var
- **Mobile App** calls the same Express backend directly

## Authentication
All endpoints (except public ones marked 🌐) require an `Authorization: Bearer <JWT>` header.
JWT tokens are generated by Firebase Auth and validated on each request via Firebase Admin SDK.

## Global Headers
```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer <token>",
  "X-Client-Version": "1.0.0",
  "X-Platform": "web" | "ios" | "android"
}
```

## Endpoints by Service

### Auth Service (`/auth`)

#### 1. POST `/auth/register` 🌐
Register via email/password.

**Request:**
```json
{
  "email": "user@example.com",
  "password": "securePassword123!",
  "name": "Ravi Desai"
}
```

**Response (200):**
```json
{
  "success": true,
  "message": "Registration successful. Please verify your email.",
  "data": {
    "user": {
      "id": "507f1f77bcf86cd799439011",
      "firebaseUid": "abc123",
      "name": "Ravi Desai",
      "email": "user@example.com",
      "createdAt": "2025-01-15T00:00:00Z"
    }
  }
}
```

**Errors:** 400 (Invalid email or weak password), 409 (Email exists), 422 (Validation error)

---

#### 2. POST `/auth/login` 🌐

**Request:**
```json
{
  "email": "user@example.com",
  "password": "securePassword123!"
}
```

**Response (200):**
```json
{
  "success": true,
  "data": {
    "token": "<JWT_ACCESS_TOKEN>",
    "refreshToken": "<REFRESH_TOKEN>",
    "expiresIn": 3600,
    "user": {
      "id": "507f1f77bcf86cd799439011",
      "name": "Ravi Desai",
      "email": "user@example.com",
      "preferences": { "theme": "dark", "defaultTab": "ai", "language": "en" }
    }
  }
}
```

---

#### 3. POST `/auth/google` 🌐
Google OAuth login. Firebase ID token passed from client.

**Request:**
```json
{ "idToken": "<FIREBASE_ID_TOKEN_FROM_GOOGLE>" }
```

**Response (200):** Same shape as email login.

**Errors:** 401 (Invalid Firebase token), 403 (Account blocked)

#### 7b. POST `/auth/fcm-token`
Register/unregister FCM token for push notifications.

**Request:**
```json
{
```
